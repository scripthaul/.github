# ScriptHaul

YouTube transcripts, in bulk. [scripthaul.com](https://scripthaul.com) turns any public video, playlist, or channel into clean transcript files, free and without an account. The [ScriptHaul API](https://api.scripthaul.com) does the same for developers and AI agents: whole-channel jobs, search inside what was said, channel libraries, monitors, and an MCP server.

Open source here:

- [scripthaul-js](https://github.com/scripthaul/scripthaul-js) and [scripthaul-python](https://github.com/scripthaul/scripthaul-python): official API clients.
- [agent-skills](https://github.com/scripthaul/agent-skills): the skill that teaches Claude, Cursor, and other agents to use ScriptHaul.
- [youtube-caption-formats](https://github.com/scripthaul/youtube-caption-formats): the caption converters behind every download.
- [scripthaul-extension](https://github.com/scripthaul/scripthaul-extension): the Chrome and Edge extension.
- [openapi](https://github.com/scripthaul/openapi): the API's OpenAPI 3.1 description.

Docs: [api.scripthaul.com/docs](https://api.scripthaul.com/docs). Support: support@scripthaul.com.
